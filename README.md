# Simple Calculator

A clean, responsive, and easy-to-use web-based calculator built using standard front-end web technologies. This project performs basic arithmetic operations seamlessly directly in your browser.

## 🚀 Features

- **Basic Arithmetic Operations:** Supports addition, subtraction, multiplication, and division.
- **Responsive Design:** Optimised layouts that fit nicely on desktop monitors, tablets, and smartphones.
- **Clean User Interface:** Modern layout styled carefully using CSS.
- **Instant Evaluation:** Leverages standard JavaScript to compute real-time mathematical expressions.

## 🛠️ Tech Stack

This project is built purely with native web technologies without external frameworks:

- **HTML5:** Structures the layout, calculator display grid, and interaction buttons (`home.html`).
- **CSS3:** Handles the styling, layout design, responsiveness, and hover effects (`style.css`).
- **JavaScript (ES6):** Powers the core computation logic, button clicks, and screen inputs (`script.js`).
